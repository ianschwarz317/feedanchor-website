# FeedAnchor — Website

Landing page for [FeedAnchor](https://ianschwarz317.github.io/feedanchor-website), a Chrome/Edge extension that automatically saves LinkedIn posts you pause on.

## Setup

This is a single `index.html` file hosted on GitHub Pages. No build step needed.

## Before launching

1. **Add your video** — replace `YOUR_YOUTUBE_VIDEO_ID` in the `loadVideo()` function at the bottom of `index.html` with your actual YouTube video ID
2. **Add store links** — replace the `href="#"` on the two install buttons with your real Edge Add-ons and Chrome Web Store URLs

## Hosting

Served via GitHub Pages from the `main` branch.
